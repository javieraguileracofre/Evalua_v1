Cómo trabajar una evaluación (orden recomendado)

  1. Armar el expediente con los documentos del checklist (SII, EEFF, deuda, garantías).
  2. Cargar números en la solicitud — el motor no lee PDFs: solo usa los campos del formulario.
  3. Correr RÁPIDO para filtrar casos claros (APROBAR / RECHAZAR).
  4. Correr PROFUNDO cuando haya flujo de caja, DSCR y garantías confiables (puede salir CONDICIONES).

Flujo rápido

APROBAR solo si se cumplen las tres condiciones a la vez; si no, RECHAZAR.

Interno: historial de pago + endeudamiento × 1,3. Default 300.
=(cuotas vigentes + cuota propuesta) / ingreso mensual × 100.
Natural: meses/12 · Empresa: años de operación.

Flujo profundo — DSCR

DSCR = flujo de caja mensual ÷ cuota propuesta. Ordene: rechazo < alerta ≤ aprobación ≤ fuerte.

Necesario (con garantía) para APROBAR.
Por debajo → RECHAZAR.
Bajo este valor: penaliza score.
Sobre este valor: bonifica score.

Flujo profundo — garantía

Cobertura % = valor liquidación ÷ monto solicitado × 100. Use liquidación, no valor comercial.

Junto a DSCR y categoría A/B/C → APROBAR.
Por debajo → RECHAZAR / penaliza.
Sobre este valor: bonifica score.

Flujo profundo — concentración de ingresos

% del cliente principal sobre ventas. Ajusta el score; no decide solo.

Sobre este %: penaliza (dependencia de un cliente).
En o bajo este %: bonifica (cartera diversificada).
